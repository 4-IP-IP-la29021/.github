<h2>一、总价由五块拼成</h2>
<p>线路月租按带宽档位计，地址费按个数计，设备或端口费按月计，开通施工费一次性，增值项按需。</p>
<p>最容易被忽略的是施工费。报价单上常单列，几百到几千不等，首月账单会比月租高出一截。</p>
<p>做预算要按首年总支出算，不要只看月租。还有一笔隐性成本：接入点没资源要等排期，等待期业务只能跑临时方案。</p>

<h2>二、线路类型决定底价</h2>
<p>同样的四个地址，跑在不同线路上价格能差几倍。普通国际带宽最便宜，优化线路贵一些，独享专线最贵。</p>
<p>差价的本质是拥塞概率和抖动水平。判断值不值，看业务对抖动是否敏感。</p>
<p>网页操作不敏感，便宜线路够用。实时语音、直播推流、长连接业务敏感，省下的钱会以体验损失还回去。</p>
<h3>别只看标称带宽</h3>
<p>标称是接口速率，实际可用受国际出口影响。要问清是保证带宽还是尽力而为。</p>
<h2>三、地址单价与起步费</h2>
<p>地址费有两种算法：含在套餐里，或者单独计价。含在套餐里的看起来免费，实际已经摊进月租。</p>
<p>单独计价时第一个地址常有起步费，之后按单价叠加。四个地址的总价不是四倍，会低一些。</p>
<p>如果地址费占总价三成以上，说明套餐带宽给得少，主要卖的是地址。低于一成，说明地址是附赠的。</p>
<h2>四、带宽与地址的交叉计价</h2>
<p>同样月租，可以选高带宽少地址，也可以选低带宽多地址。选哪个取决于瓶颈在哪里。</p>
<p>隔离场景瓶颈是地址数，选低带宽多地址。大文件传输瓶颈是带宽，选高带宽少地址。</p>
<p>两边都紧张就要加预算，没有便宜的解法。实用做法是把需求写成两行去问价，看对方能否对应。</p>
<h2>五、一次性费用与折扣</h2>
<p>开通费、设备押金、首月预付构成首期支出。有的服务商免开通费换长约，这时要算长约期内的总支出。</p>
<p>年付折扣常见一到两成。四地址套餐按月费一千估，年付省一两千，但锁定十二个月。</p>
<p>砍价顺序建议先砍开通费，再谈带宽升级，最后才谈月租。开通费一次性，对方让起来阻力小。</p>

<h2>六、三档预算参考</h2>
<p>入门档适合多环境隔离但流量不大的场景，要注意抖动。标准档是最常见组合，兼顾隔离与体验。</p>
<p>高配档适合直播、实时语音、对稳定性要求高的场景。三档价格均为区间估算，仅供参考，实际以报价为准。</p>
<p>选档的次序是先定用途，再定线路，最后比价。反过来先比价，容易买到带宽够、线路差、体验不稳的套餐。</p>
<h2>常见问答</h2>
<h3>四个地址比一个贵多少？</h3>
<p>答：通常贵三到五成，不是四倍。第一个地址含在套餐里，后续按单价叠加，带宽部分不变。</p>
<h3>可以只要地址不要带宽吗？</h3>
<p>答：不行。地址依附在线路上，没有独立于线路的纯地址产品，带宽可以选低档但不能为零。</p>
<h3>开通费一般多少？</h3>
<p>答：几百到几千不等，取决于接入点资源与施工难度。长约条件下有的服务商可免，谈价时优先争取。</p>
<h3>月付还是年付划算？</h3>
<p>答：年付折扣一到两成但锁定一年。业务稳定、需求明确的可以年付，验证阶段建议月付。</p>
